title: Visual evidence retrieval
summary: Search page and figure images separately, preserve their source coordinates, and cite original visual evidence rather than generated descriptions.
---

## What it means

A text query can retrieve a *page image*, an *extracted figure image*, or *text describing a figure*. These are different evidence units. A high page-retrieval score does not show that the right diagram was isolated, its author caption was attached, or the answer cites the right region. This extends [scientific PDF structure extraction](../scientific-pdf-structure-extraction/) and [web capture fidelity](../web-capture-fidelity/); [page relevance is not figure provenance](../../notes/page-retrieval-does-not-localize-a-figure/). In ViDoRe v1/v2 the judged unit is the page; v3 measures page retrieval and bounding-box grounding separately ([Faysse et al., 2025](../../sources/colpali-study/); [Mace et al., 2025](../../sources/vidore-two-study/); [Loison et al., 2026](../../sources/vidore-three-study/)).

**Inference:** Preserve the original PDF or rendered web capture and visual assets. Index *both* rendered pages for broad recall and source-linked figure crops for precise retrieval; separately index author captions, surrounding prose, and optional generated descriptions. Figure detection can miss or split a diagram, so a page search also offers a recovery path. Keep the retrieved unit and its provenance joined through reranking and answer generation. A Mermaid reconstruction is a derived interpretation, not the source figure, and no reviewed benchmark here measures Mermaid retrieval.

| **VLM prose or Mermaid** | Figure crops plus generation, a text index, optional visual index, and versioned derived annotations. **Inference:** These raw vector byte counts assume float32 or float16 as stated and omit ANN structures, metadata, copies, and stored source images; compare retrieval quality at matched dimensions, raster resolution, and corpus before optimizing bytes. A page index uses one item per page; crop indexing adds one item/call per detected visual. Query embedding, late-interaction scoring or ANN probes, reranking, and generative answer tokens are separate recurring costs. Record actual usage, image resizing, index bytes, and query latency rather than transferring vendor billing examples between models.

## Making a retrieved figure citable

For a PDF, retain captured URL/time and PDF hash; one-based display page and parser page index; figure label, original caption, caption box, and figure rectangle in a declared source coordinate system; page dimensions, CropBox/MediaBox, rotation, raster DPI, resize/padding transform, detector version, and a cropped render with its hash. A PDF figure may consist of text and vector paths as well as bitmap objects: cite a source-region render, not merely an extracted embedded image. GROBID's documented figure coordinates use one-based pages and upper-left PDF units and must be scaled against page dimensions and CropBox before overlaying on a rendered page ([GROBID project, n.d.](../../sources/grobid-pdf-coordinates/); [Docling project, n.d.](../../sources/docling-vision-runtime/)). Provide the original PDF page link and a stable crop/overlay link; a bare page number is not an exact figure citation.

For a web page, retain the captured URL/time/hash, rendered DOM, original `src`/`srcset` or SVG asset and resolved displayed image, the containing `figure`'s ID (or capture-scoped selector/ordinal), and author `figcaption`/alt separately. Prefer an author-supplied `#id` fragment with an archived capture/asset link; if absent, the archive's capture-scoped crop/figure link is more durable than a guessed live CSS selector. The HTML Standard defines `figure` as a unit and its first `figcaption` as the caption, but pages need not use those elements ([WHATWG, n.d.](../../sources/html-figure-specification/); [web capture fidelity](../web-capture-fidelity/)).

**Inference:** Return a citation bundle containing the source link, captured revision, page or DOM anchor, verified crop/box, and source caption; record model/prompt/version beside any generated prose or Mermaid. Check the box and caption against the original before citing an answer. When detection fails, cite the page honestly rather than fabricating figure-level precision. Evaluate page recall, figure recall, box overlap, caption pairing, and whether the citation reopens the exact evidence as distinct outcomes ([Loison et al., 2026](../../sources/vidore-three-study/); [Khalighinejad et al., 2026](../../sources/arxivdoc-retrieval-study/)).
