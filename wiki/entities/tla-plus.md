title: TLA+

---

TLA+ is a high-level language for modeling programs and systems, especially concurrent and distributed ones. Leslie Lamport frames it as a mathematical way to describe designs precisely; Learn TLA+ calls it a formal specification language that lets engineers test designs before relying on code. ([Lamport, 2025](../../sources/leslie-lamport-tla-homepage/); [Wayne, undated](../../sources/learn-tla/))

## Tools

Lamport's project map identifies the Toolbox and a VS Code extension as development interfaces. It names TLC for model checking and TLAPS for proofs as the primary checking tools. ([Lamport, 2025](../../sources/leslie-lamport-tla-homepage/))

## Learning and stewardship

[Learn TLA+](../../sources/learn-tla/) organizes instruction into a linear language Core, independent advanced Topics, and worked Examples. Lamport's homepage says project stewardship moved to the TLA+ Foundation and explicitly describes his site as a retired personal resource rather than the current project home. See [TLA+ sources pair a project map with a practical guide](../../research/tla-plus-learning/) for the source-bound comparison. ([Lamport, 2025](../../sources/leslie-lamport-tla-homepage/); [Wayne, undated](../../sources/learn-tla/))
