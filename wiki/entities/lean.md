Lean is an open-source programming language and proof assistant. Its official homepage presents the same environment as a place to write precise, verifiable programs and formal proofs, with applications in mathematics and software and hardware verification. ([Lean, 2026](../../sources/lean-lang-homepage/))

## Trust and extension

The homepage attributes Lean's correctness story to a minimal trusted kernel. It also presents metaprogramming as the mechanism for adding domain-specific notation and proof automation, making extension part of the language rather than only an external tooling layer. These are first-party project claims, not an independent assurance assessment. ([Lean, 2026](../../sources/lean-lang-homepage/))

## Entry points

Worked homepage examples combine definitions, theorem statements, and tactics such as `grind`. The site directs readers to separate installation and learning paths. See [Lean joins programming and formal proof in one language](../../research/lean-lang-website/) for the source-bound brief. ([Lean, 2026](../../sources/lean-lang-homepage/))
