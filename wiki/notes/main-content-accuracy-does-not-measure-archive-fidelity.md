---
title: Main-content accuracy does not measure archive fidelity
summary: Text-overlap benchmarks can reward correct article boundaries while missing broken tables, code, equations, and figures.
---

A page-to-Markdown pipeline can select the right prose yet corrupt the evidence that makes a technical page useful. The independent eight-dataset comparison strips structural markup and scores ROUGE-LSum word sequences: Trafilatura has macro-mean F1 **0.883**, while Readability has macro-median F1 **0.970**. Neither number assesses Markdown ([Bevendorff et al., 2023](../../sources/web-content-extraction-empirical-comparison/)). A newer, mixed-page benchmark scores bags of words: on its 511 held-out pages, Trafilatura scores **0.841**, Readability **0.736**; word order and layout do not contribute ([Foley, 2026](../../sources/wcxb-content-extraction-benchmark/)). The Trafilatura project's own 990-document snippet benchmark gives Trafilatura standard **0.924** versus a *different*, Python readability-lxml port at **0.826**; its selected snippets and vendor ownership make the figures non-interchangeable with either study ([Trafilatura project, n.d.](../../sources/trafilatura-benchmark-evaluation/)).

WebMainBench's 545-page structured subset measures another property: for Trafilatura, code edit similarity is **0.1305**, formula edit **0.6107**, and table TEDS **0.3405**. The authors' MinerU-HTML scores **0.9093**, **0.9399**, and **0.7388** on those measures, although it is their own benchmark and tests a complete extraction/conversion path. It does not measure figures or caption association ([Ma et al., 2025](../../sources/webmainbench-structure-study/)).

**Inference:** Choose a [capture workflow](../../concepts/web-capture-fidelity/) by testing both content boundaries and element-level fidelity on the archive's own pages. No cited benchmark directly ranks Firecrawl, Defuddle, Jina Reader API, Crawl4AI, and Cloudflare Markdown for Agents together; support claims and model-only scores cannot fill that gap. For comparison, the existing [Kagi API price source](../../sources/kagi-api-pricing/) calls its Extract output clean Markdown without demonstrating structure fidelity.

For scientific PDFs, [a high document-parsing benchmark score also cannot certify every structural relationship](../pdf-benchmark-scores-do-not-certify-structure/). Some protocols omit caption scoring or merge code into text, even when the parser emits readable Markdown ([Ouyang et al., 2025](../../sources/omnidocbench-study/)).
