---
title: A shared decision API does not reveal a shared model
summary: Matching typed outputs show interface compatibility, not identical weights, backbones, or training.
---

[Laya](../../entities/laya/) and [Jev](../../entities/jev/) accept state plus `choice`, `score`, and `noul` questions and produce bounded probability-valued answers. Laya even ships a Jev-compatible HTTP endpoint. That establishes a similar **external contract**, not a shared neural architecture or vendor. ConvAI Innovations publishes Laya's weights and implementation; TypeSafe AI documents Jev's interface but does not publish its weights or sufficient architecture and training details to compare internals. ([ConvAI Innovations and Laya contributors, n.d.](../../sources/laya-repository/); [TypeSafe AI, n.d.](../../sources/typesafe-system-one-documentation/))

Laya's disclosed design uses a bidirectional ModernBERT-large encoder for English or mmBERT-base for multilingual input, followed by a two-layer decision transformer and option-marker scoring head. Each question is independently encoded in a batch. Both vendors use the term RLCD for decision-oriented probability training, but TypeSafe's public description does not specify Jev's backbone or update algorithm at Laya's level of detail. **Uncertainty:** Jev may share or differ in internal components; the evidence cannot identify which. API compatibility and a shared training label do not settle the question. ([ConvAI Innovations, n.d.](../../sources/laya-model-card/); [TypeSafe AI, n.d.](../../sources/typesafe-system-one-documentation/); [TypeSafe AI, n.d.](../../sources/typesafe-machine-learning-primer/))

This distinction matters for [System One models](../../concepts/system-one-models/): interchangeability of request and response shapes can make migration easy while accuracy, calibration, context limits, and deployment differ. See [Calibration depends on the task and checkpoint](../calibration-depends-on-task-and-checkpoint/). ([ConvAI Innovations and Laya contributors, n.d.](../../sources/laya-repository/); [TypeSafe AI, n.d.](../../sources/typesafe-models-documentation/))
