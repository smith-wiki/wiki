## Overview

Tavily's documentation explains its free, pay-as-you-go, monthly, and enterprise credits and how many credits each API operation consumes. It is the vendor's own undated, mutable documentation, authoritative for the advertised credit system at capture time. A credit is not a neutral unit: an advanced search costs twice as much as a basic one, and returned content and retrieval behavior differ from other providers such as [Kagi](../kagi-api-pricing/), so converting credits into per-request prices needs care.

## Key points

- Accounts receive 1,000 free API credits each month without a credit card. (Section "Free API Credits")
- Pay-as-you-go usage costs $0.008 per credit. (Section "Pricing Overview")
- A basic Search request uses one credit and an advanced Search request uses two. (Section "API Credits Costs" > "Tavily Search")
