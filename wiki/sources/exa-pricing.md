## Description

Exa's provider-maintained price list for Search, Contents, Answer, Monitors, Deep Search, and Agent products. The evidence used here concerns standard Search and Contents units.

## Evidence

### `search-request-price`

- **Source states:** Standard Search costs $7 per 1,000 requests and includes up to ten results per request.
- **Representation:** `exa-pricing-md-2026-09-22T09:20:25Z`
- **Locator:** `Products` → `Search`; `Search, Contents, Answer, and Monitors` table → `/search`

### `additional-result-price`

- **Source states:** Each result above the first ten costs another $1 per 1,000 results.
- **Representation:** `exa-pricing-md-2026-09-22T09:20:25Z`
- **Locator:** `Search, Contents, Answer, and Monitors` table → `/search`

### `contents-page-price`

- **Source states:** Contents costs $1 per 1,000 pages for each requested content type.
- **Representation:** `exa-pricing-md-2026-09-22T09:20:25Z`
- **Locator:** `Products` → `Contents`; `Cost glossary` → `Page and content type`

## Source criticism

This mutable first-party page is authoritative for Exa's advertised prices at capture time. Its base Search price includes a stated result allowance, but result ranking, extracted content, and quality are not directly equivalent to Kagi's units.
