## Overview

The Spritely Institute's project page introduces Goblins as a distributed object programming environment for peer-to-peer applications, lists its Guile and Racket implementations, and points to design documentation and recent articles. It is an undated first-party overview for developers: good for the project's own terminology and the versions released at capture time, not for reliability, adoption, security, or performance. The architecture behind its claims is set out in [The Heart of Spritely](../the-heart-of-spritely/).

## Key points

- Goblins is a distributed object programming environment for peer-to-peer applications, with transactional local interactions, asynchronous remote interactions, debugging, persistence, and upgrade support. (Opening description)
- Guile and Racket implementations are listed, both at version 0.18.0. (Section "Get Goblins!")
- The page points to the Goblins design documentation and recent explanatory articles. (Sections "Read about Goblins' design" and "Recent articles")
