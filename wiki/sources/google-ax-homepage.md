## Claims and evidence

The homepage presents [AX](../../entities/google-ax/) as a declarative agent execution control plane: a task can compose workspaces, network gateways, and model configurations, while AX prepares the sandbox and supervises its lifecycle. Its worked terminal sequence shows a task being applied, observed, entered, suspended, resumed with a created file still present, and deleted.

The page emphasizes generative workspace setup from a natural-language goal and identifies developers and researchers as intended users. It says AX relies heavily on [Agent Substrate](../../entities/agent-substrate/) for lightweight actors, stateful suspend and resume, and dense worker sharing while AX supplies agent-oriented abstractions and generative runtime components.

## Limits

This is promotional first-party material. Claims of billions of concurrent sessions, sub-second resumption with “zero cold-start delay,” dense multiplexing, production suitability, and research lineage are not independently substantiated on the page.

**Contradiction:** The homepage heading says AX was “built for production,” while the preserved repository README warns that core concepts, protocols, and specifications are still being refined and will likely introduce major breaking changes before a stable release. Agent Substrate’s README separately says that underlying project is not production-ready.
