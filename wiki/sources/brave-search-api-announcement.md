## Overview

Brave's launch post for its revised Search API introduces an LLM Context endpoint, developer tools, one public price across search types, and a Zero Data Retention option, and reports an answer-quality evaluation that Brave ran on its own system. The vendor wrote it to win developers building AI products, so its privacy and performance statements are claims, not findings: the benchmark measures Brave's answer system rather than comparing search APIs, and the free monthly credit depends on attribution. The page was updated on September 17, 2026. Its retention promise contrasts with the temporary query logging described in [Your Privacy and Kagi](../kagi-privacy/).

## Key points

- Every Search type, including Web and LLM Context, costs $5 per 1,000 requests, with $5 of free credit each month. (Section "Simpler, cheaper and more powerful plans", Search)
- Brave offers Zero Data Retention across its Search API endpoints and says queries are not stored, logged, or linked to identities. (Section "Why you should use the Brave Search API", "Zero Data Retention (ZDR)")
