## Overview

Cohere's public pricing page describes enterprise products and includes a Model Vault table with dedicated instance prices for Embed 4. It also states that trial API calls are free but rate-limited and production API keys are pay-as-you-go. The rendered page does not publish a usable per-image Embed v4 API charge or the image-to-billable-token rule, so its hourly dedicated-instance figures must not be substituted for per-call API pricing. This is a first-party commercial snapshot, not evidence of visual retrieval quality. The [Embed model contract](../cohere-embed-four-docs/) describes accepted input and output dimensions, while the [Voyage comparison](../voyage-multimodal-three-five-release/) provides separately labeled vendor-run quality numbers.


## Key points

- Model Vault lists a dedicated Embed 4 Small instance at $4/hour or $2,500/month, and Medium at $5/hour or $3,250/month; this is not pay-as-you-go API pricing (Model Vault table).
- Trial API keys are free but not permitted for production or commercial use; production calls are billed pay-as-you-go (Frequently asked questions, trial and production keys).
- No Embed v4 per-image or per-million-image-token pay-as-you-go tariff is visible on this captured public page; a numerical per-page API estimate would require that tariff and measured usage (Model Vault table; Frequently asked questions).
