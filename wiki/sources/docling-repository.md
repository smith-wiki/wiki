## Overview

The Docling project's pinned README presents a local document converter for PDF and other formats, designed for developers who need structured content before indexing or analysis. It advertises page layout, reading order, tables, code, formulas, and image processing, with a unified document model and Markdown or JSON export. Its macOS ARM support and MIT code license are useful deployment facts; the README explicitly sends readers to individual model licenses rather than licensing every model weight itself. This is a first-party feature description, not independent evidence that each structure survives a particular scientific PDF. Compare the [Apple vision-runtime documentation](../docling-vision-runtime/) and [READoc scientific-paper results](../readoc-study/) before choosing a pipeline or quoting performance.

## Key points

- PDF layout, reading order, table structure, code, and formulas are among the advertised parsing capabilities, with Markdown and lossless JSON exports. ("Features")
- The project lists macOS arm64 among supported installation environments and local execution among its capabilities. ("Installation"; "Features")
- The codebase is MIT licensed; model licensing is delegated to the original packages and must be checked for the chosen models. ("License")
