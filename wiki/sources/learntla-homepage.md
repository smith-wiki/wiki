## Overview

Hillel Wayne's Learn TLA+ homepage introduces a free guide to TLA+, arguing that design flaws survive even perfectly written code and that TLA+ lets engineers test designs directly. It lays out the guide's sequential Core lessons, optional Topics, and worked Examples. Wayne is a TLA+ educator and consultant, so the framing is partly promotional rather than an evaluation of effectiveness; the page carries a 2022 copyright and calls the guide a work in progress. The [conceptual overview](../learntla-conceptual-overview/) provides the concrete worked example.

## Key points

- Code defects can violate a design, while design defects persist even in faithfully implemented code. Wayne positions TLA+ as a formal specification language for directly testing designs, supplementing engineering rather than replacing it. (`Learn TLA+`, paragraphs beginning "Most software flaws" and "TLA+ is a formal specification language")
- The guide divides its material into sequential Core lessons, optional Topics, and worked Examples; it points newcomers to its conceptual overview. (`About this guide`)
